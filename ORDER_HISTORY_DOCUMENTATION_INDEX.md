## 💡 Key Concepts

### API Integration
- Endpoint: `GET /api/Order/my-orders`
- Parameters: pageIndex, pageSize
- Response: paginated order list with items array

### Status Mapping
- `all` → Show all orders (no filter)
- `Pending` → Yellow badge, awaiting payment
- `Paid` → Green badge, payment confirmed

### Pagination
- Page controls with Previous/Next buttons
- Page indicator (e.g., "Trang 1/6")
- Disabled when on first/last page

### Component Structure
- OrderHistory (page) → manages state and API calls
- SortBar (filter) → status selection
- OrderList (container) → maps orders to cards
- OrderCard (display) → shows complete order
- StatusBadge (badge) → colored status indicator
- ProductItem (item) → shows product in order
